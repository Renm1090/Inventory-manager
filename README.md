# 📦 Inventory Manager (Android)

> Aplicación móvil moderna y ligera para la gestión y control eficiente de inventarios, desarrollada en Python con Flet y compilada de forma nativa para Android.

---

## 🚀 Características Principales

* **Interfaz Móvil Intuitiva:** Diseño limpio y adaptado a pantallas táctiles gracias a las capacidades multiplataforma de Flet.
* **Control de Stock en la Palma de tu Mano:** Registro, consulta y actualización rápida de artículos directamente desde tu dispositivo.
* **Portabilidad:** Diseñada para llevar el control de inventarios sin depender de un equipo de escritorio.

---

## 🛠️ Tecnologías y Herramientas

* **Lenguaje:** [Python](https://www.python.org/)
* **Framework UI:** [Flet](https://flet.dev/) (Arquitectura Flutter)
* **Plataforma Objetivo:** Android

---

## 📲 Instalación (APK)

Puedes instalar la aplicación directamente en tu dispositivo Android de manera muy sencilla:

1. **Descarga el archivo APK** más reciente desde la sección de [Releases](../../releases) de este repositorio o transfiérelo a tu teléfono.
2. Habilita la opción de **Instalar desde fuentes desconocidas** en la configuración de seguridad de tu Android si el sistema te lo solicita.
3. Abre el archivo `.apk` en tu dispositivo y presiona **Instalar**.
